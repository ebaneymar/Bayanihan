# SUHANAYAN 1.2.9

In **Sari-sari Store → Ako ang tindero**, serve four customers, count out change in pesos, and compare the four receipts. Open the count-up guide during a turn or try a different combination of coins. The activity works in Filipino and English.

**Existing Windows installation:** open **Mga setting → Mga update sa GitHub**, check for the update, and choose **I-update ngayon**. The updater loads the new game content from `game.html`.

**For a new Windows installation:** open `BayanihanMath.exe`, then use the same update steps to load v1.2.9. This download is the existing Windows launcher from v1.2.8.

**For offline play:** extract `SUHANAYAN_1.2.9_Offline.zip` and open `game.html` in your browser. The ZIP includes the updated game and its source.
